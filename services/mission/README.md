# services/mission — Motor de Missões™

Implementa o fluxo Intenção → Missão → Objetivos → Projetos → Execuções → Resultados definido nas Etapas 2 e 3. É o serviço que, no produto final, transforma uma intenção capturada (por texto, voz ou WhatsApp) em uma Missão estruturada com objetivos e execuções.

**Status:** pasta reservada. `apps/web/lib/mock-data.ts::MOCK_MISSIONS` e `packages/types::Mission` definem o formato de dados que este serviço deverá produzir.

**Entra em fase futura:** criação de missões via Nova™, cálculo de progresso, decomposição automática em objetivos/execuções, priorização automática (Etapa 2).
